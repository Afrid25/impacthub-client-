# ImpactHub – Social Development Events Platform

ImpactHub is a full-stack web application where people can explore and participate in social development activities. Users can create events, join community programs, and manage their own events.

The project focuses on making social activities like tree plantation, environmental cleanup, blood donation, food distribution, and educational programs easier to organize.

## Live Website

https://impacthub-frontend-gold.vercel.app

## Key Features

- User registration and login with email/password or Google
- Explore upcoming social development events
- View event details and join events
- Create, update, and delete personal events
- View created and joined events separately
- Search, filter, and sort events
- Secure authentication and protected routes
- Responsive design with dark and light mode
